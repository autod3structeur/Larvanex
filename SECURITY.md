# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅        |

## Reporting a vulnerability

If you believe you have found a security vulnerability in Larvanex itself
(for example, a crash caused by a crafted input, or a way the tool could be
tricked into executing content), please **do not open a public issue**.

Instead, report it privately using GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
feature on this repository, or email the maintainer.

Please include:

- A description of the issue and its impact.
- Steps to reproduce, ideally with a minimal non-working proof-of-concept.
- The version and platform you tested on.

You can expect an acknowledgement within a few days.

## Scope

Larvanex is a **static** analysis tool. It reads bytes and never executes the
files it scans. The relevant risk surface is therefore limited to input
parsing (PDF, ZIP, OLE) and outbound network calls to MalwareBazaar.

## A note about samples

This repository ships only **synthetic, harmless** sample files generated by
`samples/generate_samples.py`. They contain trigger markers (magic bytes and
keywords) but no functional malicious code. Please do not submit real malware
in issues or pull requests — share a SHA-256 hash instead.
